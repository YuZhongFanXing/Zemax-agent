name: verify-zemax-model
description: Compare geometry and views from a reopened native model with a source drawing.
---
Use measured sections to check dimensions, topology, count, pitch, angles and termination. Match named orthographic and section views to the drawing, using the axonometric view to corroborate shape. Identify drawing-based estimates separately from tolerance checks. Require evidence for both geometry and view verdicts. STEP and STL are optional.
